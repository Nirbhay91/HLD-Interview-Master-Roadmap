## Solution Framework

Every problem will eventually be solved using a consistent interview framework:

1. Clarify Functional Requirements
2. Clarify Non-Functional Requirements
3. Estimate Scale — DAU, QPS, peak QPS, storage, bandwidth
4. Define Core APIs
5. Draw High-Level Architecture
6. Choose Database and Data Model
7. Add Cache / CDN / Object Storage where required
8. Define Synchronous vs Asynchronous communication
9. Define Kafka / Queue / Event flows where required
10. Design for scalability
11. Design for availability and fault tolerance
12. Handle consistency and distributed-system problems
13. Add security and authorization
14. Add observability
15. Identify bottlenecks
16. Explain trade-offs
17. Give a 2–3 minute interview summary
18. Prepare follow-up questions

> Problems will be solved one by one, starting from Tier 1. This directory is the detailed Phase 10 problem roadmap; detailed solutions will be added as each problem is covered.
